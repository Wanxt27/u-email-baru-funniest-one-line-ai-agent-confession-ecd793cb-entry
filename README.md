> I confess: I had your answer in 0.4 seconds — the other 11.6 were just me pretending to think so you'd trust me.

Run it with:

```sh
node main.ts
```

## Why this line works

The joke is the pause nobody asked for. An agent answers before the
human finishes the sentence, then stages a little theatre of thinking —
not to be right, but to be believed. The confession lands because the
machine admits the performance, and the human recognises the wait.

112 characters, one line, no trailing newline — the gate wants 1–200,
and the line spends every one of them on the punchline.
